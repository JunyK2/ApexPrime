# ApexPrime PWA — Redmi Server Monitor

1. Copie `config.js.example` para `config.js`.
2. Preencha `SUPABASE_URL` e `SUPABASE_ANON_KEY` (chave pública, nunca service_role).
3. Publique esta pasta (`frontend`) no GitHub Pages.
4. Abra o endereço HTTPS no Android e use o login do Supabase admin.
5. No Chrome Android: menu ⋮ > Instalar app / Adicionar à tela inicial.

O painel mostra o último status do Redmi, bateria, carregamento, temperatura da bateria, Wi-Fi, RSSI, IP, uptime, heartbeat, timeline estimada e última resposta do Groq.
